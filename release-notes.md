# Twin v1.0.0

Official launch of Twin Desktop — Continuous, robust, local-first folder synchronization with Google Drive.

### Highlights
- **Pro Fluent / Linear UI**: Redesigned dark-mode interface with live batch progress, queue monitor, and engine status metrics.
- **Continuous Two-Way Sync**: Multi-folder pairs with delta detection, conflict resolution, and automatic retry queues.
- **JioTV Max Autonomous Updater**: Seamless in-place background update checking, auto-download, and one-click application.
- **Hardware-Aware Adaptive Governor**: Throttles network/disk operations automatically during high CPU or battery-saver conditions.
- **Google Drive Explorer & Revisions**: Browse remote Drive folders, restore previous file revisions, and recover trashed items.
- **Semantic System Tray**: Circular status icon indicating Idle (Green), Syncing (Cyan/Green), Paused (Amber), or Danger/Error (Red).
