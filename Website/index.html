Specifications

Built for precision workflows.

Arbitrary Folder Pairs
Map any local path to any Drive ID in Upload, Mirror, or Two-way modes.
Revision History
Inspect revisions, pin "Keep forever", and restore lost versions directly.
Google Docs Export
Automatically converts Docs, Sheets, and Slides to offline .docx, .xlsx, and .pptx.
Windows Credential Store
Hardware-backed token encryption. Zero plaintext secrets on disk.
Deterministic Sync
True byte progress bars, smoothed EMA speeds, and plain error diagnostics.
Resource Governor
Auto-pauses sync on high system CPU (>70%) or critical battery (<20%).
