Core Value Proposition

Engineered to eliminate sync frustration.

Most cloud sync utilities conceal what they do behind vague spinners while hogging laptop memory and spinning up fans. Twin was built with three uncompromising goals.

01

Simplified Process Understanding

No more wondering why a file is stuck or what is being uploaded. Twin provides 100% visibility into every transfer state, retry backoff, and chunk completion.

  • Byte-Accurate Progress: Real bytes done and total bytes, never fake jumpy percentages.
  • Smoothed EMA Speed: Accurate network throughput and reliable ETA countdowns.
  • Transparent Error Log: Plain-text diagnostic messages with automated exponential backoff counters.
02

More Features Than Google Drive

Break free from Google's virtual drive restrictions. Enjoy arbitrary folder pairing, in-app revisions browsing, and native office document exports.

  • Arbitrary Multi-Folder Pairs: Map any local directory on any drive to any remote Google Drive folder ID.
  • In-App Revisions Vault: Browse past versions, pin "Keep Forever" flags, and restore directly to any folder.
  • Docs/Sheets/Slides Export: Convert online Google Docs automatically into offline .docx, .xlsx, and .pptx files.
03

Ultra-Lightweight Rust Performance

Crafted with Rust Tokio and Tauri 2. No heavy Python processes or bundled Chromium web engines running in the background while you work or game.

  • ~28 MB RAM: Consumes 95% less system memory than Google Drive for Desktop.
  • Hardware CPU Governor: Automatically pauses transfers when host CPU > 70%, keeping fans silent.
  • Battery Aware: Suspends heavy background syncing when laptop battery drops below 20% on DC power.

Comprehensive Capabilities

Designed for power users, developers, and professionals.

Every subsystem was purpose-built to give you complete sovereignty over your data and local storage.

Multi-Pair Arbitrary Routing

Bind any directory across internal SSDs or external drives directly to any Google Drive folder ID. Assign distinct sync policies: Upload only, Mirror (with deletion sync), or Two-way.

Debounced Priority Queue

Rapid file modifications (like code saves or exports) are debounced by 3 seconds. Transfer queues feature exponential retry backoffs (1s, 2s, 4s, 8s, up to 5 min) with auto-retry.

16 MiB Resumable Chunks & Parallel Fetch

Large uploads are sliced into resumable 16 MiB chunks so interrupted transfers resume seamlessly. Downloads larger than 32 MB utilize 4 parallel ranged streams simultaneously.

Windows Credential Manager Security

Hand-crafted OAuth 2.0 PKCE loopback authentication. Tokens are stored encrypted in the native hardware-backed Windows Credential Manager—never saved in unencrypted config files.

Google Workspace Office Exporter

Google Drive only leaves useless .gdoc link stubs. Twin automatically exports Google Docs into .docx, Sheets into .xlsx, and Slides into .pptx so you can view and edit your documents anywhere.

GitHub Sync-State Auto-Backup

Twin periodically serializes your sync state metadata and pushes it to your private GitHub repository every 30 minutes, giving you instantaneous disaster recovery if a local drive fails.
