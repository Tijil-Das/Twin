Frequently Asked

Got questions? We have answers.

Google Drive for Desktop bundles Python runtimes, Chromium web instances, and virtual file system drivers that stay in memory constantly, burning 450 MB to 1.2 GB of RAM. Twin is compiled into native machine code using Rust and Tauri 2, utilizing Windows native components only when UI is displayed. Idle in the tray, it uses just ~28 MB RAM.
Yes. Unlike Google Drive which isolates your files inside a virtual G: drive letter or a single folder tree, Twin allows you to configure unlimited folder pairs anywhere across your drives (C:, D:, external storage, etc.), with individual sync modes (Upload, Mirror, or Two-way) per pair.
Twin monitors host CPU load and battery state using native Windows system calls. If total system CPU usage exceeds 70% for 5 seconds (e.g., during video encoding or gaming), Twin automatically pauses sync transfers to yield resources to your foreground apps, resuming when CPU drops below 50%. It also suspends syncing when laptop battery drops below 20% on unplugged state.
Yes. Authentication uses official OAuth 2.0 with PKCE loopback. All tokens are encrypted and stored in the native Windows Credential Manager. No passwords or OAuth tokens are ever written in plaintext files.
